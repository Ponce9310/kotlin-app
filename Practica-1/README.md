# Guía Práctica: Kotlin Básico 🚀

Este repositorio contiene la resolución de la guía práctica de introducción a Kotlin, desarrollada como parte de la asignatura de Desarrollo de Aplicaciones Móviles en Duoc UC.

## 🎯 Objetivo de la Actividad
El propósito de este proyecto es familiarizarse con la sintaxis y características fundamentales de Kotlin, comparándolas directamente con Java para comprender sus ventajas en cuanto a concisión y seguridad.

## 🛠️ Conceptos Aplicados
El código fuente (ubicado en `src/Main.kt`) aborda los siguientes desafíos técnicos:
* **Variables y Operadores Aritméticos:** Declaración de variables y operaciones matemáticas básicas.
* **Seguridad ante Nulos (Null Safety):** Uso de variables opcionales (`String?`) y el operador de llamada segura (`?.`) para evitar colapsos en la aplicación.
* **Lógica Condicional:** Implementación de la estructura de control `when` como alternativa moderna y segura al `switch` tradicional.

## 💻 Entorno de Desarrollo
* Lenguaje: Kotlin
* IDE: IntelliJ IDEA
* JDK: 17 o superior
